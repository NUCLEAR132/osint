# OSINT

مستودع لملاحظات وموارد استخبارات المصادر المفتوحة (OSINT).

## الهدف

تنظيم الأدوات والمصادر العامة المستخدمة في البحث والتحقق من المعلومات المتاحة علنًا.

## الاستخدام المسؤول

- استخدم المعلومات والموارد المتاحة للعامة فقط.
- احترم الخصوصية والقوانين وشروط استخدام المواقع.
- لا تستخدم هذا المستودع للمضايقة أو التتبع أو الوصول غير المصرح به إلى الحسابات والأنظمة.
- تحقّق من المعلومات من أكثر من مصدر، واذكر المصادر عند مشاركة النتائج.

## المساهمة

يمكن إضافة موارد موثوقة وملاحظات مفيدة، مع توضيح مصدرها وتاريخ التحقق منها.
